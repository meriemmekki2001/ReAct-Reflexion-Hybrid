# Experimental protocol

## Research question

How do tool-assisted reasoning (ReAct) and unconditional verbal self-reflection (Reflexion) affect performance on multi-hop factual QA and grade-school mathematical reasoning, individually and when combined?

## Implementation details

The refactor keeps the original core logic:

1. **Baseline:** single LangChain `ChatOpenAI.invoke` using a question-only prompt.
2. **ReAct:** `ChatOpenAI.bind_tools`; repeated assistant/tool observations; at most six loop iterations; a final non-tool model call when the limit is reached. The recorded trajectory contains each tool call and observation.
3. **Reflexion:** first answer, one independent critique, then a second answer prompted with the critique as episodic memory. Two attempts always occur.
4. **Hybrid:** ReAct first attempt, critique of the answer and tool trajectory, ReAct second attempt with reflection memory. Two attempts always occur.

The Hybrid and Reflexion agents do not use an oracle correctness signal. Reflections are generated by the model itself. Both can regress from correct first attempts.

## Dataset and information access

| Benchmark | Data split | Sample selection | Baseline / Reflexion | ReAct / Hybrid |
| --- | --- | --- | --- | --- |
| HotpotQA | distractor validation | first N (no shuffle) | question only | question + BM25 document search / read |
| GSM8K | main test | shuffled with seed 42, first N | problem only | problem + calculator |

These conditions preserve the original experimental setup but introduce unequal evidence/tool access. Do not claim that gains over Baseline isolate reflection or planning alone.

## Metrics and interpretation

**HotpotQA:** EM and F1 in [0,1]. **GSM8K:** numeric accuracy in [0,1]. A score of 0.61 corresponds to 61% correct. `First_Accuracy` is the first attempt, `Accuracy` the final attempt. `Recovery_Rate` = recovered / initially incorrect (successful executions only). `Regressed` counts correct-to-incorrect transitions. `Avg_Time` is wall-clock seconds per question and agent. `Avg_Tool_Calls` counts actual tool invocations, not LLM calls or tokens.

When comparing ReAct and Hybrid, also inspect cost: Hybrid systematically makes two ReAct attempts and one reflection call. Performance gaps of only a few points on N=100 are uncertain; consider a larger sample or paired bootstrap confidence intervals for formal claims.

## Reproduce the original sampling

```bash
python -m agent_bench.cli --benchmark hotpotqa --num-examples 100 --results-dir results/hotpotqa-100
python -m agent_bench.cli --benchmark gsm8k --num-examples 100 --seed 42 --results-dir results/gsm8k-100
```

These commands use the same sampling conventions as the source experiments, but the repository does not contain archived model outputs. For reproducibility, commit a dependency lock file after validating the environment, e.g. `pip freeze > environment-lock.txt`, and record model snapshot/version where available.

## Reporting checklist

- Report all four agents, including failures and neutral/negative findings.
- Report attempted and successful executions, not only conditional accuracy.
- Distinguish first-attempt from final accuracy.
- Report whether reflections recover or regress answers.
- State that HotpotQA baseline has no candidate documents, whereas ReAct does.
- State that GSM8K tools differ from HotpotQA tools.
- Avoid interpreting differences across benchmarks as causal proof of generalization.
